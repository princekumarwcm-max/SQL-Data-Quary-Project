# 🍕 Pizza Sales Analysis Using SQL

### 📊 Data Analysis | MySQL | Business Intelligence

## 📌 Project Overview

This project focuses on analyzing pizza sales data using **MySQL** to uncover meaningful business insights and understand sales performance.

The objective is to explore sales trends, customer ordering patterns, popular pizza categories, revenue contributions, and product performance by writing SQL queries.

The project includes 13 business-oriented SQL questions covering Basic, Intermediate, and Advanced SQL concepts.

## 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Identify the most popular pizza types and sizes.
- Calculate total sales revenue.
- Understand hourly and daily order trends.
- Analyze category-wise pizza sales.
- Identify top-performing pizzas based on revenue.
- Calculate revenue contribution percentages.
- Analyze cumulative revenue over time.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **IDE:** MySQL Workbench
- **Dataset Format:** CSV
- **Analysis Techniques:** Joins, Aggregations, Subqueries, Window Functions

## 🗄️ Database Structure

The project uses the following four tables:

| Table Name | Description |
|---|---|
| orders | Stores order dates and times |
| order_details | Stores order-level pizza details and quantities |
| pizzas | Stores pizza sizes, IDs, and prices |
| pizza_types | Stores pizza names and categories |

## 📊 SQL Analysis & Business Questions

### 🟢 Basic Level
1. Retrieve the total number of orders placed.
2. Calculate the total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Identify the most common pizza size ordered.
5. Find the top 5 most ordered pizza types with their quantities.

### 🟡 Intermediate Level
6. Find the total quantity of pizzas ordered for each category.
7. Determine the distribution of orders by hour of the day.
8. Find the category-wise distribution of pizzas.
9. Calculate the average number of pizzas ordered per day.
10. Identify the top 3 most ordered pizza types based on revenue.

### 🔴 Advanced Level
11. Calculate the percentage contribution of each pizza category to total revenue.
12. Analyze cumulative revenue generated over time.
13. Find the top 3 most revenue-generating pizza types in each category using window functions.
